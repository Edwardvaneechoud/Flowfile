### Illustration style guide (applies to every diagram below)

Read this once; the per-row **Icons & illustration** notes assume it.

- **Palette** — Flowfile's brand gradient (from `docs/stylesheets/extra.css`): cyan `#2DD5D3` → cerulean `#26A8E0` → royal `#1D76D6` → navy `#233588`. There is **no orange** (extra.css overrides the MkDocs default accent to cyan).
- **Color hierarchy is the message.** Put anything *Flowfile* in the brand gradient; render the thing being replaced or contrasted (spreadsheets, file copies, the old painful way, neighboring systems) in neutral grey `#9aa0a6`. Let **one** color point; everything else recedes. Use cyan `#2DD5D3` for the arrows/highlights that carry the eye.
- **Icons** — Material Design Icons (`:material-*:`), the exact set the docs already render via `pymdownx.emoji`. Flat, single-weight line icons; consistent stroke and radius. Don't mix filled brand logos with line icons except recognizable marks (Python, Kafka, Docker, Git).
- **Node motif** — for anything depicting a *flow*, reuse the real Flowfile node look (rounded rects + edges). The actual node glyphs live in `docs/assets/images/nodes/*.svg` (`input_data`, `filter`, `formula`, `join`, `group_by`, `output`, …) — drop those straight in so canvas diagrams match the app.
- **Composition** — left→right reading. The "before / painful / many copies" side small, muted, tangled; the "Flowfile" side clean, gradient, single. Contrast of *complexity* is what sells every one of these.
- **Theme-aware** — pages render light and dark. Export on transparent background using mid-brand blues (cerulean `#26A8E0` / royal `#1D76D6`, which read on both), or build inline HTML + `:material-*:` icons so it adapts automatically. The `ff-path-teal` / `ff-path-purple` classes in `extra.css` give the exact border/tint.
- **Restraint** — resist a 5th/6th icon or extra source logos; clutter kills the read. draw.io items are technical flowcharts (orthogonal edges, decision diamonds), no warmth. The one exception to "flat and cool" is `recipe-to-flow` — the plain-language page is the only place a warm, hand-drawn sketch is on-brand.
